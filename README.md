# 괴현상관리국 (괴담 위키) v1.5.0

누구나 문서를 쓰고 고칠 수 있지만, **관리자가 승인한 내용만** 문서에 반영되는 위키입니다.
Cloudflare Workers + D1(데이터베이스)로 동작하고, 무료 플랜에서도 데이터가 유지됩니다.
설치할 패키지가 없어서 `node_modules` 폴더가 생기지 않습니다.

## 폴더 구성

```
wrangler.jsonc      Cloudflare 설정 (database_id를 여기에 붙여넣음)
src/worker.js       서버 (API, 승인 처리, 관리자 인증)
public/index.html   화면 뼈대
public/style.css    디자인
public/app.js       화면 동작
public/_headers     보안 헤더
```

## 처음 올리기 (Cloudflare)

Cloudflare 무료 계정과 Node.js 18 이상이 필요합니다. 프로젝트 폴더에서 명령 프롬프트(cmd)를 열고 순서대로 입력하세요.

1. 로그인

   ```
   npx wrangler login
   ```

   브라우저가 열리면 허용을 누릅니다.

2. 데이터베이스 만들기

   ```
   npx wrangler d1 create gwandam-wiki-db
   ```

   결과에 나오는 `database_id` 값을 복사해서 `wrangler.jsonc`의 `"여기에-D1-database_id를-붙여넣기"` 자리에 바꿔 넣고 저장합니다.
   (wrangler가 설정 파일에 자동으로 추가해도 되느냐고 물으면 거절하고 직접 붙여넣는 쪽이 간단합니다.)

3. 올리기

   ```
   npx wrangler deploy
   ```

   처음이면 `workers.dev` 주소 이름을 정하라고 나옵니다. 끝나면 `https://gwandam-wiki.내이름.workers.dev` 같은 주소가 출력됩니다. 표 만드는 작업은 첫 접속 때 자동으로 됩니다.

4. 관리자 비밀번호 정하기 (꼭 하세요)

   ```
   npx wrangler secret put ADMIN_PASSWORD
   ```

   입력창에 비밀번호를 쓰고 Enter를 누릅니다. 입력한 글자는 화면에 보이지 않습니다. 비밀번호를 정하기 전에는 관리자 로그인이 되지 않습니다.

5. 접속해서 `#/admin` (왼쪽 메뉴의 "관리자")에서 로그인합니다.

비밀번호를 바꾸고 싶으면 4번을 다시 하면 되고, 이전에 로그인한 기기는 로그아웃됩니다.

## 내 컴퓨터에서 먼저 써보기

1. 프로젝트 폴더에 `.dev.vars` 파일을 만들고 한 줄을 적습니다.

   ```
   ADMIN_PASSWORD=테스트비밀번호
   ```

2. 아래 명령을 실행하고 `http://localhost:8787` 으로 접속합니다. 이때 쓰는 데이터는 내 컴퓨터에만 있고 인터넷에 올라간 것과 별개입니다.

   ```
   npx wrangler dev
   ```

## 수정 후 다시 올리기

파일을 고친 뒤 `npx wrangler deploy` 만 다시 실행하면 됩니다. 문서 데이터는 그대로 남습니다.

## 사용 방법

- 방문자: 문서 읽기, 새 문서와 편집 **제안** 보내기. 보낸 제안은 "내 제안"에서 대기, 승인, 거절 여부와 거절 사유를 볼 수 있습니다.
- 관리자: 승인 대기 목록에서 **바뀐 줄만 비교**해서 보고 승인이나 거절(사유 입력 가능). 바로 저장, 이전 판으로 되돌리기, 문서 삭제도 가능합니다.
  - **고쳐서 승인**: 제안을 그대로 받기엔 아쉬울 때 공포도와 본문을 직접 고친 뒤 반영합니다. 고치는 동안 위쪽 비교가 바로 바뀌고, 변경 기록에는 요약 끝에 "(관리자 수정)"이 붙습니다.

## 스팸 방지 켜기 (Turnstile, 선택)

"로봇이 아닙니다" 확인을 제안 보내기에 붙입니다. 무료이고, 두 값을 모두 설정하면 켜지고 하나라도 없으면 꺼진 채로 동작합니다.

1. Cloudflare 대시보드의 Turnstile 메뉴에서 위젯을 추가합니다. 도메인에는 내 사이트 주소(예: `gwandam-wiki.내이름.workers.dev`)를 넣고, 위젯 모드는 Managed를 고릅니다. 만들면 **사이트 키**와 **비밀 키**가 나옵니다.
2. 프로젝트 폴더에서 명령 프롬프트(cmd)로 두 값을 넣습니다.

   ```
   npx wrangler secret put TURNSTILE_SITE_KEY
   npx wrangler secret put TURNSTILE_SECRET
   ```

   각각 사이트 키, 비밀 키를 붙여넣고 Enter를 누르면 바로 적용됩니다. 다시 올릴 필요는 없습니다.
3. 끄고 싶으면 `npx wrangler secret delete TURNSTILE_SECRET` 을 실행합니다.

관리자의 "바로 저장"에는 이 확인이 붙지 않습니다.

## 백업과 복원 (관리자)

관리자 화면의 **백업** 탭에서 합니다.

- **문서 내려받기**: 모든 문서를 파일 하나(`gwandam-backup-날짜.json`)로 저장합니다. "변경 기록도 포함"을 켜면 이전 판들도 같이 담깁니다.
- **백업에서 복원**: 백업 파일을 고르면 문서를 다시 올립니다. 같은 내용은 건너뛰고, 내용이 다른 문서는 백업의 내용이 새 판으로 올라갑니다. 백업에 없는 문서는 건드리지 않습니다. 한 번에 500개 문서까지 가능합니다.

## 새 제안 알림 (선택)

새 제안이 들어오면 디스코드로 알림을 받을 수 있습니다.

1. 디스코드 서버의 채널 설정 → 연동 → 웹후크에서 새 웹후크를 만들고 URL을 복사합니다.
2. 프로젝트 폴더에서 아래 명령을 실행하고 URL을 붙여넣습니다. 다시 올릴 필요는 없습니다.

   ```
   npx wrangler secret put NOTIFY_WEBHOOK_URL
   ```
3. 끄려면 `npx wrangler secret delete NOTIFY_WEBHOOK_URL`

## 오늘의 괴담, 무서웠어요

- 대문에 날짜(한국 시간)마다 문서 한 편이 "오늘의 괴담"으로 나옵니다. 눌러야 보이는 글(`||...||`)은 가려서 보여줍니다.
- 문서 아래의 "무서웠어요"를 누르면 수가 올라가고(한 사람이 문서당 한 번), 전체 문서에서 "무서웠어요 많은 순"으로 정렬할 수 있습니다.

## 격리 등급과 문서 번호

- 문서마다 만든 순서대로 번호(괴-0001)가 붙습니다. 대문과 도움말에는 붙지 않습니다. 기존 문서는 처음 접속할 때 만든 순서대로 번호가 붙습니다.
- 관리자는 문서 화면에서 격리 등급(안전, 주의, 위험, 봉인)을 지정할 수 있습니다. 전체 문서에서 "격리 등급 높은 순"으로 정렬됩니다.

## 목격담

문서 아래의 "이 괴담을 겪었거나 들은 적이 있나요?"에서 누구나 짧은 이야기(500자)를 남길 수 있고, 관리자가 승인해야 문서에 보입니다. 관리자 화면의 "목격담" 탭에서 승인과 거절을 하고, 승인한 목격담은 문서 화면에서 삭제할 수 있습니다. 알림 웹후크를 설정했다면 새 목격담도 알려줍니다.

## 충돌 합치기

제안을 보낸 뒤 문서가 바뀌었다면 승인 화면에 "자동으로 합치기"가 나옵니다. 제안이 시작한 판, 지금 문서, 제안 세 가지를 줄 단위로 비교해 서로 다른 곳을 고친 경우는 합쳐줍니다. 같은 줄을 둘 다 고쳤으면 `<<<<<<<` 표시가 남으니 직접 고친 뒤 "고친 내용으로 승인"을 누르세요. 제안을 시작한 판이 오래돼서 기록에서 지워졌다면 자동 합치기는 나오지 않습니다.

## 제안 제한

반려한 제안과 목격담에는 "제한 점수"가 붙고(거절할 때 체크 해제 가능), 같은 접속에서 7일 안에 3번 반려되면 24시간 동안 제안과 목격담을 보낼 수 없습니다. 이후 반려될 때마다 24시간씩 늘어나고 최대 7일입니다. 승인되면 점수가 1점 줄어듭니다. 관리자 화면의 "제한" 탭에서 현재 제한 중인 접속을 보고 해제할 수 있습니다. 접속 정보(IP)는 비밀번호와 섞은 해시로만 저장하고 번호 앞 8자리만 보여줍니다.
